# fifo
This module is the event queue used inside [symbol_book](overview.md). It stores the latest top-of-book snapshots generated by one symbol so the external [arbiter](../../arbiter.md) can pop them later.
## Introduction
In [symbol_book](overview.md), this FIFO is instantiated as `event_fifo_inst`.

Its role is straightforward:

1. one `symbol_book` generates snapshot events when its best bid or ask changes
2. the snapshot is pushed into this FIFO
3. the global [arbiter](../../arbiter.md) decides when to pop that symbol's next event

So the FIFO decouples **event generation** from **round-robin output scheduling**.
